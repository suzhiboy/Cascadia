## 阶段 3 · 落子与回合反馈

市集选取、补件与淘汰、版图落子和局部计分飘字复用常驻节点。合法动物格按试摆分差着色并显示数值，观察卡加入缩略图。轻量动画关闭后立即落定。八种独立木质合成音使用原音量设置，正式录音清单在 assets/audio/sfx/README.md。TURN VISUALS 与 UI PERSISTENCE 均为 0 failures，SFX 为 8 distinct clips。完整规则、独立测试、渲染和四进程联机通过。部分音频播放实例在测试进程结束时报告释放诊断。

## 阶段 4 · 单人挑战、电脑对手与记录

离线各席可选择人类或两档电脑。先遍历前沿与不同旋向，以接边数和邻居数筛选每张岛块的两个位置，再用实际计分器评估动物落点、放归和跨组标记开销。普通档选择最高候选，简单档在前四项中抽选。1–4 人共 200 回合无非法动作，实测最慢一步 43.005 ms。支持暂停、快进、观战及读档恢复。

每日挑战依本机日期重现起始区、观察卡及抽取顺序。正式离线对局以独立编号原子写入本地统计，重复读取终局不会重复计数，损坏文件可恢复。AI、每日 UI 与统计测试均为 0 failures。规则 1010/0、全部独立测试及练习与 100 回合渲染通过。四进程联机首轮与独立测试撞端口，单独重跑通过，四端散列一致。


## 阶段 5 · 结算、语言与导出

「调查轨迹」展示各席在同一轮末的总分曲线、每人得分增量最大的一步和终局地图。步前至步后的差值包含刷新与跨组选取开销。缺少历史的旧存档从恢复后继续记录。简体中文、英文可在设置切换。四个实际导出均成功，Windows 可执行文件的产品名、文件版本、产品版本已核对。Web 在 Chrome WebGL 2 中进入主菜单，未显示局域网入口。非 Windows 桌面版的新版提示打开配置仓库的发布页。
