# 局域网联机
两台电脑都使用同一份最新包，连接同一热点。房主点击「局域网联机 → 创建房间」。
朋友可点击自动发现的房间；若列表为空，输入房主窗口列出的热点网卡 IPv4 地址。
不要输入 127.0.0.1，它只指向自己的电脑。多网卡电脑以 Windows 设置中热点连接的 IPv4 为准。
等待房主显示两人已连接，再点击开始。游戏端口为 UDP 35721，发现端口为 UDP 35722。

连接失败会在约 12 秒后显示原因提示。Windows 防火墙需允许这份 TidetraceIsles.exe 在当前网络类型通信。
部分热点会隔离客户端，即便同一热点也不能互访；这种情况下可换允许设备互访的 Wi-Fi 路由器。
无需开放公网端口。
