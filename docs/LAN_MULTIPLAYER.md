# 局域网联机

桌面版支持 2–4 人同局。所有玩家须使用相同版本的《潮痕群岛》，并连接同一个允许设备互访的局域网。当前源码使用联机协议 4。旧协议房间不会出现在自动发现列表中，直接输入地址也会在握手时提示版本不兼容。

1. 房主从主菜单进入「局域网联机」，创建房间。
2. 其他玩家选择自动发现的房间。列表为空时，输入房主窗口显示的局域网 IPv4 地址。多网卡电脑应选连接同一局域网的网卡地址。
3. 客人点击「准备好了」。如果房主更改观察卡，客人需要重新准备。所有座位都已连接且客人准备后，由房主开局。

房主负责同步游戏状态。掉线的客人可以在 120 秒内重连仍然运行的房间，超时会结束房间。

## 连接问题

- 默认游戏端口为 UDP 35721，自动发现使用 UDP 35722。联机仅需局域网访问。
- `127.0.0.1` 是本机地址。Windows 防火墙需要允许 `TidetraceIsles.exe` 在当前网络类型通信。
- 某些热点隔离客户端，会阻止同一热点内的设备互访。此时可换用允许设备互访的 Wi-Fi 路由器。

四个本机进程已各完成 20 回合并得到相同的终局散列。测试命令见[验收入口](TESTING.md)。
