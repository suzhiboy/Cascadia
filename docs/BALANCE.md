# 潮痕群岛 · 计分平衡记录

## 复跑方式

使用项目所需版本的 Godot，在仓库根目录运行以下命令。

```sh
godot --headless --path . --script tools/balance_sim.gd
```

本次使用 Godot 4.7.2，连续运行种子 917337–919336，共 2,000 局完整单人对局，每局 20 回合。每回合均匀抽取同一列的地块与动物、一个合法扩展位置和一个旋转方向，再从所有合法格中均匀选择动物落点。无合法落点时放归，不主动刷新或跨列选取。行动由游戏正式接口执行。决策随机种子为开局种子的 17 倍，独立于牌库抽取。

每局结束后，让四张同物种卡对同一张岛图分别计分，每张卡有 2,000 个样本。方差采用总体方差，单位为分²。验收按四张卡中最高均分除以最低均分，要求比值不超过 1.30。此记录描述随机布局，玩家围绕某张卡规划时会改变得分分布。

## 同物种均分跨度

- 招潮蟹的最高 / 最低均分为 1.093。
- 帽贝的最高 / 最低均分为 1.208。
- 燕鸥的最高 / 最低均分为 1.246。
- 弹涂鱼的最高 / 最低均分为 1.052。
- 水獭的最高 / 最低均分为 1.133。

首轮随机对局中，蟹群共享食场与水獭上岸晾毛的加分触发较少。最终将每格共享食场奖励调为 3 分，将空闲干岸奖励调为 4 分。招潮蟹 B 的剩余一条开口边也可加分。调整后在相同种子上重跑全部对局，五种动物均达到上述标准。
