# 规则口径

本版本以计划指定的 AEG 基础规则书为主。复核发现部分作者论坛说明与书中文字不同。本次按已批准计划保留书面口径，不加入另一套可切换规则。

| 项目 | 本版本行为 | 复核依据 |
| --- | --- | --- |
| 鲑鱼分叉 | 相连鱼群有任意个体邻接三只或更多鲑鱼，整群不计分 | 规则书第 11 页的有效鱼群和不可邻接其他鲑鱼条件。作者后来提出仅排除违规个体，属于不同口径 |
| 麋鹿 D | 按卡面连续圆环片段组合，选择不重复动物的最高分 | 规则书要求卡面所示环形。作者后续说明允许环中缺口，此版未采用 |
| 麋鹿 C | 相连群 8 只及以上为 28 分，不拆分群 | 按卡面 8+ 与「每个相连群」处理。未采用无法直接核验的二手拆群转述 |
| 鹰的视线 | 中间至少隔一个六角位置；其他鹰阻挡，空地不阻挡 | 规则书未明确最小间距，以作者对视线定义的说明补充 |
| 连续过剩刷新 | 先暂存，整个过剩流程结束后归袋 | 遵循书面顺序。极端情况下余袋不足抽取下一批，先归还更早暂存的批次，当前正在更换的批次仍在新抽取之后归还，保证对局可继续 |
