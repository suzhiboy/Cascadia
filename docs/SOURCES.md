# 创作与署名

六角地块与成组选取机制的灵感来源之一是桌游 Cascadia。

本项目重新设计了五种生境的地块目录、起始调查区、二十张观察卡及其规则说明、交互图例和教学。地块目录见 TILES.md，计分与模拟见 BALANCE.md。潮间带图标、地块纹样和矢量图鉴为本项目制作。

## 音乐

三首随包曲目为 Beyond Evergreen Sea、雨幕鸦语、Crow Calls over Rain（混音）。项目提供者于 2026-11-25 确认三首均已获得公开再发行授权，并将补充作者署名与许可条款。两首雨声作品为不同录音文件。音效在项目内合成。

## 字体与引擎

随包 Noto Sans SC 来自 [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosanssc)，使用 SIL Open Font License 1.1，许可证位于 `assets/fonts/OFL.txt`。Godot Engine 使用 MIT 许可证，导出发行时应附引擎及第三方组件的许可清单。`tools/write_licenses.gd` 可从运行时提取清单。
